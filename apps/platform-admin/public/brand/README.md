# ZIMOS brand assets

Approved ZIMOS logo exports. Never redraw, retype, recolour, stretch, rotate, outline or add effects.

- zimos-logo-light.png: full logo for light surfaces (darken blend)
- zimos-logo-dark.png: full logo, white wordmark, for navy surfaces (lighten blend)
- zimos-mark-tile.png: icon-only mark on its navy app-icon tile
- zimos-icon-*.png: favicons and app icons

## Required for final output

The approved logo only exists as raster exports with a baked-in background. Supply the official transparent SVGs (primary logo, white-wordmark logo, icon-only Z) and replace these files. The blend-mode workaround in packages/ui/src/brand/zimos.css can then be removed.
